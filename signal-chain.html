Direct answer

Is the aux→soundcard path where the problem is?

Yes. But the aux send itself is the right tap point for an analog mixer — there's no better option without buying new gear. The problem isn't using the aux; it's how it's configured and what it's plugged into.

How to get clean vocals without instruments overpowering

The aux send has a separate level knob per channel. Turn the aux send UP on vocals (Ch 1-9), DOWN on drums/bass/keys (Ch 10-15). That single knob per channel is the stream mix balance — totally independent of the FOH faders.

The four steps (matched to the diagram)

A Configure Aux send properly

  • Check the manual for whether the aux is switchable between PRE and POST fader. Set it to PRE-FADER. On many analog mixers there's a small "PRE/POST" button per aux.
  • Per-channel aux send knob targets:
    • Vocals (Ch 1-9): 0 dB / unity / "12 o'clock"
    • Kick (Ch 10): -12 dB / 9 o'clock
    • Snare (Ch 11): -12 dB
    • Overheads (Ch 12, 13): -8 dB
    • Bass (Ch 14): -6 dB
    • Keyboard (Ch 15): -6 dB
  • Test: turn vocal aux sends OFF temporarily, listen on headphones — you should hear ONLY drums/bass/keys. Then turn vocals back up. Adjust until vocals dominate.

B The TEYUN Q-16 is killing you (two ways)

1) Level mismatch. Q-16's mic input expects ~-50 dBu (mic level). Your aux is +4 dBu (pro line level). That's ~50 dB too hot — the Q-16's ADC clips before any gain knob can help. Pulling the mixer's aux fader down compresses dynamic range without fixing it.

2) DSP effects are probably ON. The Q-16 has built-in reverb / echo / vocal-changer / sound-pad effects enabled by default. They get baked into the USB output before OBS sees the audio. Turn them all OFF (hold the FX/RVB/ECH/VOC buttons) — this alone may make a huge audible difference.

Temporary band-aid: 20 dB inline pad on the cable into the XLR mic input + all DSP off. Real fix: replace the Q-16 (see step C).

C Buy a real USB audio interface

$100–150 buys you everything you need:

  • Focusrite Scarlett 2i2 (~$170)
  • Behringer UMC202HD (~$90)
  • PreSonus AudioBox GO (~$80)

Cable: ¼″ TRS (balanced) → ¼″ TRS (balanced) from your aux out to the interface's input. Do not use a 3.5mm adapter.

On the interface, switch the input to LINE (not MIC, not INSTRUMENT). Use the gain knob until OBS peaks read about -10 dBFS.

D Add Compressor + Limiter in OBS

  • In OBS, right-click the audio source → Filters.
  • Add a Compressor: Ratio 3:1, Threshold -18 dB, Attack 6 ms, Release 60 ms, Output gain 0 dB.
  • Add a Limiter after it: Threshold -1.0 dB, Release 60 ms.
  • Optional Expander or Noise Gate on the front to clean up between songs.
  • Optional EQ: high-pass at 80 Hz so kick rumble doesn't muddy headphone playback.

Stage monitors (passive wedges, separate from FOH)

The signal chain for passive monitors

Passive monitors need their own power amp — they are NOT driven from the main FOH amps:

Mixer Aux 1 (¼″ TRS) → Monitor Amp Input → Speakon → Passive Wedge

One aux send + one amp channel = one independent monitor mix. Run two aux sends (e.g., Aux 1 for lead vocalist, Aux 2 for band side) into a stereo monitor amp for two different mixes.

Recommended amps for typical 12″ wedges: Crown XLi 1500 / 2500, QSC GX3 / GX5, Behringer KM750. Match amp wattage to wedge spec (typical 12″ wedge = 200-400W program).

Set aux levels for monitors per-channel

  • Set Aux 1 / Aux 2 to PRE-FADER (so FOH faders don't change what the band hears).
  • On the vocalist's monitor (Aux 1): turn UP their own vocal channel, turn down everyone else's.
  • On the drummer's / band-side monitor (Aux 2): turn UP keys/bass, moderate drums (the drummer hears the kit acoustically already), light vocals.
  • Use the monitor amp's input gain knobs to set overall wedge volume.

Why a separate amp matters

Your main FOH amps (Crown XTi 4002 / 2002) are sized for the main JBL SRX speakers — way too much power for a small wedge, and they're already busy driving the room. Sending monitor signal through the FOH amp would mean:

  • You'd hear the FOH mix on stage, not a custom monitor mix.
  • No independent volume control for the stage.
  • Risk of frying passive wedges (FOH amp output is multiple kilowatts).

Dedicated monitor amp = correct power match + completely independent control.

Soundcard before the drums hit the audio link?

No — don't do this

Drum mics already output the right kind of signal (balanced mic-level XLR) for the audio link and the mixer's mic preamps. Inserting a soundcard in between would:

  • Convert analog → digital → analog for no benefit.
  • Add latency (a few ms each way) — the drummer would hear themselves late on stage.
  • Add noise (every A/D and D/A conversion adds quantisation noise).
  • Require power + a computer running drivers at the drum kit.
  • Then run back out of the soundcard at line level — which would then need a re-amp / DI to get back to mic level for the mixer's preamp. Pointless.

The soundcard belongs at the OUTPUT of the mixer (Aux → Audio Interface → OBS), not at the input to the audio link.

What you CAN add at the drums (if you want)

If you want better drum control without a soundcard, consider:

  • Drum sub-mixer: A small analog mixer (Mackie 1402VLZ4, Behringer Xenyx) at the drum riser. Pre-mix all 4 drum mics into a stereo pair, send 2 channels to your audio link instead of 4. Frees up channels on the main mixer.
  • Inline drum compressors: A dbx 166xs between drum mic and audio link tames kick/snare transients before they hit the mixer.
  • Drum trigger module (Roland TM-2 / TM-6): if you want to layer sampled drum sounds with the mics, this sits between mics and audio link.

None of these are needed for your stream problem — they're separate upgrades for drum tone control.

Stage acoustics — why your mix levels keep climbing

Main speakers are only ~10 ft from an uncaged drum kit. This is the single biggest reason vocals get buried and the mix creeps louder over the service. Until the bleed at the source is reduced, no aux-send or OBS plugin can fully clean it up.

The feedback cascade — how the mix creeps up over a service

  1. Vocalist sings → PA reproduces vocal → vocal energy reaches drum mics 10 ft behind the speakers.
  2. Drum channels in the mixer now carry: drum sound + vocal bleed + PA wash.
  3. Vocal mics simultaneously pick up the open kit acoustically (kit is 10 ft in front of them).
  4. Engineer pushes vocals harder to overcome the masking.
  5. Drummer hears louder PA on stage → plays harder → drum mics get hotter → bleed worsens.
  6. Whole system gain-creeps upward every 10 minutes.

The 10 ft distance also causes ~9 ms latency between PA-bleed and direct drum sound — creating comb filtering (frequency-domain hollowness) on every channel.

What this means for your stream

Critical implication: even with every drum / bass / keys aux-send-to-stream set to OFF, the vocal channels are still picking up the kit acoustically. The stream can never be "vocals only" — it's "vocals + drum bleed in the vocal mic capsule." That's a hard physical limit until the bleed is reduced at the source.

With the aux/interface/OBS fixes, you'll still get a vocal-forward, non-clipping stream. Just don't expect studio-clean isolation while drums are uncaged.

Caging the drums — three tiers

Shielding the drums will help more than any other single change you could make. Every 6 dB of bleed reduction is roughly half the perceived loudness.

TIER 1 · DIY · $50-100

Hang sound blankets or moving blankets on a frame behind and beside the kit.

Reduction: ~3-5 dB at high frequencies. Helps with cymbal wash; not much help for kick/snare.

Best if budget is genuinely zero.

TIER 2 · Standard · $300-500 START HERE

5-panel clear acrylic drum shield, 4 ft tall, no hood. Brands: Pennzoni, Clearsonic A2466x5, ChromaCast.

Reduction: ~6-8 dB. Sweet spot for your room and proximity.

Skip the hood unless you can't get the shield-only to work — hood adds heat for the drummer and changes drum tone.

TIER 3 · Full enclosure · $1000-1500

5-7 panel shield with angled hood/ceiling — Clearsonic Megapack.

Reduction: ~10-15 dB. Maximum isolation. Heat / ventilation considerations.

Non-shield alternatives for reducing drum volume

Low-volume drum heads · $150

Remo Silentstroke or Evans dB One mesh heads. Cut drum acoustic by 60-80%. Drummer plays with normal sticks. Mics pick up the heads at near-normal level; the room hears the kit at maybe 50% of normal volume.

Low-volume cymbals · $200-400

Zildjian L80, Sabian Quiet Tone. Cymbals are the worst bleed offender — they're aimed up, ringing into the whole room and overhead mics for seconds.

Brushes / hot rods · free

Instant ~10 dB reduction. Changes feel and groove — stylistic call.

Electronic drum kit · $600+

Entry-level Roland/Alesis. Nuclear option — kills the bleed problem entirely. Sometimes the right answer for small venues with streaming.

Sanity check — confirm bleed is the dominant problem

Quick test (15 min, before band call)

With band off stage but PA running at performance level, play back a recorded vocal at performance loudness through the FOH speakers. Watch the drum mic meters on the mixer.

  • If drum mic channels show more than -30 dBFS just from FOH spill → bleed is dominant, focus on shielding first.
  • If drum mic meters stay quieter than -30 dBFS → bleed isn't the main problem; gain staging on the aux or soundcard input level is more likely.

About your TEYUN Q-16

Important context: the Q-16 is a budget streamer/karaoke "sound card", not a pro audio interface in the Focusrite/Behringer UMC class. It's designed for a single person doing solo livestreams, gaming, or karaoke — with a built-in DSP that does reverb, echo, voice changer, and sound-effect pads. That DSP is probably also contributing to your audio problems.

What's likely wrong with the Q-16 in your current setup

  • DSP effects probably ON: reverb / echo / vocal changer can be enabled by default and are baked into the USB output. This alone can make the stream sound muddy, slappy, or weird.
  • Mic input expects mic-level signal (~-50 dBu) — your mixer's aux out is +4 dBu line level. That's about 50 dB too hot. Same clipping problem as before, just inside the Q-16 instead of a 3.5mm jack.
  • 3.5mm "AUX IN" is for phone music playback (Bluetooth/3.5mm stereo at consumer level) — also not designed for a +4 dBu pro line signal.
  • The 1/4" output is unbalanced on most TEYUN models, despite looking like a balanced TRS. Run short cables if you use it.
  • Mono USB output: most TEYUN Q-series interfaces send a mono mix to USB even when the unit shows stereo metering. Check OBS to confirm.
  • 48 kHz only — fine for streaming, but limits any future use as a recording interface.

How to make the Q-16 work as cleanly as possible (no new gear)

  1. Turn OFF every DSP effect: hold the FX/RVB/ECH/VOC buttons until they're disabled. Verify by speaking into a mic — should be dry with no reverb tail or echo.
  2. Plug mixer aux → Q-16 XLR mic input with an inline 20-30 dB pad on the cable (Whirlwind IMP-Pad ~$30, Shure A15LA ~$40). The pad drops line level down to mic level the Q-16 expects.
  3. OR use a DI box in reverse: mixer aux ¼" out → DI box ¼" input → DI box XLR output → Q-16 mic input. Active DI like the Radial J48 you have can work, but check signal polarity.
  4. Set the Q-16's gain knob to minimum, then nudge up while watching OBS meters. Target -10 dBFS peaks.
  5. Add Compressor + Limiter filters in OBS on the Q-16 audio source.

Honest recommendation: spend $80-150 on a real interface

The Q-16 is the wrong tool for this job. You're plugging a pro mixer into a karaoke device — even with pads and effects bypassed, it will always sound less clean than it could.

For $80-180 you can get a proper interface designed exactly for accepting a mixer aux line signal:

  • Behringer UMC22 — ~$60. 1 XLR/¼" combo mic input, 1 ¼" instrument input, balanced TRS outputs, USB. Real ASIO drivers.
  • Behringer UMC202HD — ~$90. 2 combo inputs (perfect for stereo aux), real LINE switch, balanced outputs.
  • Focusrite Scarlett Solo — ~$120. Best-in-class preamp, clean line input.
  • Focusrite Scarlett 2i2 — ~$180. Two combo inputs, the de facto standard for streaming.

Any of these will accept the mixer aux at line level directly, no pad needed. The Q-16 can become your stream operator's confidence-monitor mixer if you want to keep using it.

What to do with the Q-16 after you upgrade

  • Confidence monitor for the operator: feed the new interface's balanced output INTO the Q-16's AUX IN — now the operator can hear the stream on headphones plugged into the Q-16, completely separate from the loud room.
  • Talkback mic: plug a cheap mic into the Q-16 for the operator to communicate with the band/leader between songs (output to a stagebox or IEM system).
  • Backup recorder: a separate audio capture in OBS that records the Q-16 output as a redundant track.

Buying a USB audio interface on AliExpress — evaluation checklist

AliExpress is full of audio interfaces ranging from genuinely good (Behringer / iCON / M-Vave units) to repackaged junk (generic "live sound cards" that are just rebranded TEYUN-style streamer mixers — the exact thing you're trying to replace). Use the checklist below to evaluate any listing before buying.

MUST-HAVE features (for your aux→stream use case)

  • Combo XLR / ¼″ TRS input jack on the front (looks like an XLR with a hole in the middle for the TRS).
  • LINE / MIC switch or an INST/LINE/MIC selector — confirms it can accept +4 dBu line level from your mixer aux.
  • Dedicated gain knob per input.
  • Balanced ¼″ TRS outputs on the back (NOT just RCA or 3.5mm).
  • USB-B or USB-C data port (not a USB-A "thumb drive" port — that's for playback files, not audio I/O).
  • Class-compliant USB Audio — works on Windows / Mac with no special driver. Confirm in the listing description or reviews.
  • 48 kHz or higher sample rate. 96 kHz / 24-bit is ideal.
  • +48V phantom power switch (only matters if you ever connect a condenser mic later).

RED FLAGS — walk away if you see these

  • Built-in "effects" / DSP buttons labelled FX, reverb, echo, vocal changer, sound pads (laughter, applause). That's a streamer/karaoke mixer, not an audio interface — same category as your Q-16.
  • "Live sound card" in the title is usually a red flag — it's marketing language for streamer mixers, not pro interfaces.
  • Multiple "channels" advertised as 16 / 24 / 48 with a small physical unit — those are DSP scenes/effects, not actual audio channels.
  • Bluetooth music streaming as a featured spec — designed for solo karaoke, not pro use.
  • "Sound effect pads" — entertainer mixer.
  • Only 3.5mm jacks, no ¼″ or XLR. Cheap consumer-grade.
  • No brand name at all, or generic "Professional USB Sound Card" — usually means unsupported, no drivers, undocumented internals.
  • "Auto-tune" or "voice change" as a feature — entertainer use case.
  • Battery powered — bus-powered USB devices are best, battery-powered are for podcasters on the go.

Known-good brands available on AliExpress

  • Behringer UMC22 (~$60-100 on AliExpress): 1 XLR/TRS combo, 1 ¼″, balanced TRS outs, real ASIO drivers. The de facto budget recommendation.
  • Behringer UMC202HD (~$90-130): 2 combo inputs, 24-bit/192 kHz, balanced outs. Better than UMC22.
  • Behringer UMC204HD / UMC404HD (~$130-200): 4-channel versions — useful if you ever go to dual-source streaming.
  • iCON Cube 4Nano / Cube G: Chinese brand, legit pro interface line. Decent build quality.
  • M-Audio M-Track Solo / Duo (~$80-120): Real M-Audio products on AliExpress are fine.
  • Focusrite Scarlett Solo / 2i2 (3rd or 4th gen) (~$120-200 on AliExpress, $130-200 retail elsewhere): industry standard. Verify authenticity — many fakes exist on AliExpress.
  • M-Vave SMC-Mixer series: Chinese, but legitimate company with real drivers. Look for "audio interface" not "live sound card" in their lineup.

⚠️ Counterfeit warning: Focusrite Scarlett is the most-counterfeited interface on AliExpress. Check seller ratings, recent reviews mentioning genuine Focusrite drivers/registration, and serial numbers. If a Scarlett 2i2 is priced under $100, it's likely fake.

  1. Look at the photo of the front face: count the jack types. If you see XLR + ¼″ combo + LINE/MIC switch + gain knob → good. If you see effect buttons + 3.5mm only → bad.

Advanced approach — dual-source streaming (clean vocals + instruments separately)

Instead of relying on one aux send from the main mixer, you can tap the wireless receivers directly for vocals (their 1/4" outputs are unused right now), submix those through a small vocal mixer with USB out, and feed that to OBS as Source 1. The main mixer's aux out becomes Source 2 (instruments only, with vocal aux sends turned OFF). OBS mixes the two sources — giving you total control over vocal vs instrument balance, totally independent of the FOH engineer.

This works because every Shure ULXD4Q receiver has two output jacks per channel: a balanced XLR (currently feeding your main mixer) and an unbalanced 1/4" jack (currently unused). The 1/4" output carries the same audio as the XLR — just a parallel feed.

Detailed setup — dual-source approach

Hardware required

  • Small vocal sub-mixer with USB out:
    • Yamaha MG16XU (~$400, 10 mic inputs)
    • Behringer Xenyx X1832USB (~$400, 12 mic inputs)
    • Allen & Heath ZED-12FX (~$500, 6 mic + 4 stereo)
  • A proper audio interface for the aux feed (Behringer UMC22 ~$60, UMC202HD ~$90, or Focusrite Scarlett Solo ~$120). The TEYUN Q-16 is not suitable for receiving a +4 dBu aux signal even with a pad — replace it for this approach.
  • 9× ¼" TRS to ¼" TRS cables (RX 1/4" outs → vocal sub-mixer inputs)
  • 1× ¼" TRS balanced cable (main mixer aux out → audio interface input)
  • 2× USB cables (vocal sub-mixer → PC, audio interface → PC)

Wireless RX configuration

  • Each ULXD4Q channel has both an XLR output AND a ¼" output — same audio on both, parallel feed.
  • XLR outputs: keep connecting to the main mixer's vocal channels 1-9 (for FOH PA — unchanged from current setup).
  • ¼" outputs (currently unused): connect to the vocal sub-mixer's 9 inputs.
  • The RX's internal output level for the ¼" jack: usually a menu setting — set to line level (not mic level) so it matches the vocal sub-mixer's ¼" line inputs.

Vocal sub-mixer configuration

  • Set each input switch to LINE (not MIC — they're getting line-level signal from the RX).
  • Gain knob: 9 o'clock to start, adjust per vocalist for healthy meter level.
  • Channel faders at unity (0 dB).
  • EQ: high-pass filter ON for each vocal channel (cuts kick rumble).
  • Optional: pan vocalists across stereo image for a wider broadcast.
  • USB output: connects directly to PC via USB-B cable.

Main mixer aux configuration (instruments only)

  • Pick an unused aux (e.g., Aux 4). Set it to PRE-FADER.
  • Vocal channels 1-9: aux send fully OFF (knob at -∞).
  • Drum / bass / keys channels 10-15: aux send at unity (0 dB), adjust to taste.
  • Aux output (¼" TRS line) → balanced cable → audio interface's ¼" TRS input (set to LINE, gain at noon).

OBS configuration (the actual mix)

  • Add two Audio Input Capture sources:
    • Source 1: "USB Audio Mixer" (or whatever the vocal sub-mixer appears as) → name it "Vocals"
    • Source 2: "Scarlett 2i2" (or your existing interface) → name it "Instruments"
  • On Vocals source → Filters: Compressor (3:1, -18 dB) + Limiter (-1 dB). Set fader to -3 dB.
  • On Instruments source → Filters: HPF 80 Hz + Limiter (-1 dB). Set fader to -12 dB.
  • Use a Reaper or Voicemeeter virtual cable if you need finer routing, but OBS native audio sources work for most setups.

Pros of this approach

  • Total independence from FOH engineer — vocals can't be ruined by main mixer settings.
  • Vocals get fresh preamps — no signal sharing with the main mixer's gain stage.
  • You can mix the stream in real time in OBS with two simple faders.
  • If the main mixer crashes/has issues, vocals on the stream are unaffected.
  • Uses what you already have on the RX side — just buys one mixer.

Cons / things to watch

  • Two-mixer workflow: someone has to learn the small mixer.
  • RX 1/4" outputs are usually unbalanced — keep cable runs short (under 5 m / 15 ft) to avoid hum.
  • Instrument bleed in the vocal mics still passes through — same physical limit as before (the cage problem doesn't go away).
  • Adds one more device to power and maintain.
  • If a vocalist is on a wedge monitor fed from the main mixer aux 1/2, that wedge mix is unaffected — but make sure aux numbering doesn't collide.

When to use this vs the simpler single-source approach

  • Use dual-source if: you have an unreliable FOH engineer, the main mixer is hard to access from the stream position, or you want maximum stream quality.
  • Stay single-source (mixer aux only) if: budget is tight, the FOH engineer is competent and reliable, and you've fixed the aux send levels + interface input properly. Single-source can sound excellent if configured right.
  • Hybrid option: take only the lead vocalist's RX 1/4" output direct to the audio interface (channel 3/4), leave the others on the main mixer. Cleanest vocal where it matters most, simpler than full dual-source.
